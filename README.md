A Python program — standard library only, no network — that sums up the world news of Tuesday 24 November 2026 in one image. It renders a 1024×1024 newspaper front page, "THE WORLD IN ONE DAY": the day's lead story (the Cikande candy-factory fire in Banten, Indonesia, with 28 workers still missing) plus ten more stories from five continents, each with a headline and a two-line factual summary, all drawn with a hand-authored vector stroke font rendered at 2× supersampling and PNG-encoded with zlib. It writes /output/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png), byte-identical on every run.

## Run it

```sh
python3 main.py
```
